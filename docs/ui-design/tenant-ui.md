# SmartRent 租户端 UI 设计需求（rent-app 小程序 · 租客视角）

> 用途：本文档供 AI/设计师据此产出**租户端**（微信小程序）的 HTML 界面。
> 技术栈：uni-app / Vue3 + Vite。底部 4 个 Tab：首页 / 助手 / 消息 / 我的。
> 阅读对象：UI 生成 Agent。请先读"统一设计语言"，再逐页实现；移动端尺度用 `rpx`（750 基准）。

---

## 一、统一设计语言（必须遵循）

### 配色（墨黑 · 香槟金 · 高级风，2026-07-17 更新）
> 视觉以 `docs/ui-prototype/*.html` 为准。原青绿 `#0f766e` 已弃用，改为墨黑底 + 香槟金点缀。
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 Primary | `#c9a86a`（香槟金）/ `#e2c690`（亮金） | 主按钮、激活态、链接、金线 |
| 深色块 Deep | `#0e0f13` / `#16181f` | 首页 hero、详情顶部、各页头部、消息顶部 |
| 金线 / 描边 | `rgba(201,168,106,.30)` | 分隔线、卡片高光、聚焦环 |
| 强调 Accent | `#b8893f`（深金） | 价格、金额、评分 |
| 页面背景 | `#f5f3ee` | 暖米灰 |
| 卡片底 | `#ffffff` | 描边 `#e9e4da` |
| 标题文字 | `#1b1c20` | |
| 正文 | `#56524b` / `#928c80` | |
| 状态语义色 | `#5aa06b` / `#cf9b4e` / `#cf6a6a` / `#8a93a3` | 成功 / 警告 / 危险 / 信息 |

### 字体 / 圆角 / 阴影
- 字体：`PingFang SC` / `Microsoft YaHei`。
- 卡片圆角 `16~24rpx`；按钮 `12~16rpx`；标签/胶囊 `999rpx`。
- 阴影：`0 10rpx 26rpx rgba(31,42,46,0.04)`（卡片），深块用 `0 18rpx 40rpx rgba(20,59,52,0.16)`。
- 列表卡片通用结构：白卡 + 1rpx 描边 + 轻阴影；点击 `:active` 轻微 `scale(0.99)`。

### 通用房源卡片（用于首页/搜索/收藏跳转等）
- 左侧封面图（约 218×186rpx，圆角 12rpx，缺图用 `/static/default-house.png`）。
- 右侧：标题（超长省略）+ 评分徽标；地址（区域·详细）；meta 行（户型/面积/出租方式 小灰底 chip）；tag 行（绿底标签，最多 3）；底部行：价格（橙，大号）+ "次浏览" + "导航"胶囊。

## 四、首页（pages/index/index）

**顶部 Hero（深色 `#18332f`，下圆角 30rpx）**
- eyebrow：`SmartRent`；主标题：`找到适合日常生活的房子`。
- 搜索卡（白底）：放大镜图标 + 占位"搜索区域、地铁、小区或户型" → 点击跳转搜索页。
- 快捷标签行：`近地铁` / `可短租` / `有电梯`（半透明白胶囊）。
- 智能找房助手卡：左侧"AI"方块（亮绿 `#9ff0da`）+ 标题`智能找房助手`+ 副标题`一句话说需求，帮你整理区域、预算和房源选择`+ 箭头 → 跳转助手页。

**筛选栏**（横向滚动 chips）：`整租` / `合租` / `一居` / `两居` / `三居`（激活态绿底白字）。

**推荐区**：标题`推荐房源` + 右侧"N 套在租"（总数）。

**房源列表**：通用房源卡片（见通用结构）。支持下拉刷新、触底加载更多。
- 加载态：骨架屏（3 张占位卡，shimmer 动画）。
- 空态：`暂无匹配房源` / `换个筛选条件再看看。`。

## 五、房源搜索（pages/house/search）

**搜索壳（深色 `#18332f`，圆角 20rpx）**
- 搜索框（白底）：放大镜 + 输入（聚焦自动聚焦，回车搜索）+ 清除"×"。
- `搜索` 按钮（橙 `#d97706`）。

**未搜索时**：常用搜索面板（白卡）标题`常用搜索`+ 副标题；快捷标签：`近地铁`/`两居`/`整租`/`有电梯`/`海淀区`/`可短租`。

**已搜索时**：结果头（`搜索结果` + `N 套匹配房源` + 关键词"xxx"）；结果列表（同通用房源卡）。
- 空态插画（纯 CSS 房子图形）+ `没有找到相关房源` + 建议文案。

## 六、房源详情（pages/house/detail）

**顶部**：图片轮播（swiper，自动播放、指示点，高 520rpx）；底部渐变遮罩。

**主信息卡**（白卡，上移盖住轮播）
- 标题 + 评分徽标（`x分`，橙底）。
- 价格行：`¥价格/月`（橙，大号）+ 出租方式胶囊（绿底）。
- meta chips：户型 / 面积 / 楼层 / 装修。
- 地址行：区域 + `距地铁 Xm`。

**位置与路线卡**
- 区块头：`位置与路线` + 副标题"像店铺导航一样，点'去这里'直接打开微信地图" + `地图`链接。
- 地址 + `距你 X` 距离徽标。
- 地图组件（有坐标时显示，否则占位"该房源暂未配置坐标"）。
- `去这里` 深色路线卡（标题+描述+导航按钮）。
- 出行方式：`步行` / `骑行` / `驾车`（三胶囊）。
- 通勤网格（3 格）：到地铁 / 通勤商圈 / 当前位置。
- 周边参考：地铁站名 + 距离。

**房源亮点**：tag 列表（绿底）。
**配套设施**：tag 列表（浅底）。
**房源描述**：正文段落。

**底部固定栏**（白底上边框）：`收藏`（切换已收藏红底）/ `去这里` / `预约看房`（主按钮绿，整宽 → 跳预约页）。

## 七、预约看房（pages/house/appointment）

**Hero（深色，下圆角）**：kicker `SmartRent` + 标题`预约一次放心看房` + 副标题 + 三个要点胶囊（实地采光/通勤核对/费用确认）。

**表单卡（白卡）**
1. 看房时间：日期 picker（start=今天）+ 时间 picker（两列）。
2. 联系方式：电话输入框（仅本次看房确认）。
3. 备注：textarea（选填，看房关注点）。

**提交面板**：`提交后等待确认` 说明 + `确认预约` 主按钮（绿）。校验：时间+电话必填；提交后提示"预约已提交"并返回。

## 八、智能找房助手（pages/agent/chat）

**Hero（深色）**：kicker `SmartRent Agent` + 标题`智能找房助手` + 副标题（告诉我预算、通勤和居住偏好…）+ 右侧"AI"方块 + `首页`链接（返回显示原生 TabBar）。

**建议标签**：`6000以内海淀两居` / `通勤中关村怎么选` / `合租要注意什么` / `帮我推荐近地铁房源`（点击直接发送）。

**对话区**（scroll-view，撑满剩余高度）
- 消息：助手左（"助"头像 + 白气泡），用户右（"我"头像深底 + 绿气泡）。
- 加载态：助手"正在分析你的需求..."打字气泡。

**输入栏**（底部固定白底）：输入框（占位"例如：预算6000，想住海淀，通勤中关村"）+ `发送`按钮（绿）。

- 空态气泡插画 + `暂无消息` + 说明。

## 十五、偏好设置（pages/my/preference）
