# SmartRent 房东端 UI 设计需求（rent-app 小程序 · 房东视角）

> 用途：本文档供 AI/设计师据此产出**房东端**（微信小程序，与租户端同工程 `rent-app`）的 HTML 界面。
> 房东身份在登录后由 `role=1` 判定，"我的"页会出现"房东工作台"入口。
> 阅读对象：UI 生成 Agent。请先读"统一设计语言"，再逐页实现；移动端尺度用 `rpx`（750 基准）。

---

## 二、入口说明
- 房东登录后，在 `pages/my/index` 的菜单中出现"房东工作台"（深底图标"住"，副标题"房源、预约、带看进度"）。
- 房东同样可使用：消息中心、我的账单、我的合同、评价房源等公共页面（字段见租户端文档，此处不重复）。
- 房东专属页面共 3 个：`landlord/dashboard`（工作台）、`landlord/publish`（发布房源）、`landlord/appointments`（看房预约）。

---

## 三、房东工作台（pages/landlord/dashboard）

**顶部**
- eyebrow：`房东工作台`；标题：房东昵称（或用户名，取 `userInfo.nickname || username`）。
- 右上 `发布` 主按钮（绿）→ 跳发布页。

**指标卡（3 格网格）**
| 指标 | 字段 | 说明 |
|---|---|---|
| 房源 | `houses.length` | 该房东房源总数 |
| 已上架 | `onlineCount` | `status===1` 的数量 |
| 待确认 | `pendingAppointments` | 看房预约 `status===0` 的数量 |

**我的房源（区块头：标题 + `刷新`链接）**
- 房源列表卡（白卡，左封面图 176×148rpx + 右侧信息）：
  - 标题 + 状态徽标：`已上架`(绿)/`已下架`(浅橙)/`待审核`(橙)。
  - meta：`区域 · 户型 · 面积m²`。
  - 底部：价格（橙，`¥x/月`）+ 操作：
    - 未上架显示`上架`；已上架显示`下架`；始终显示`删除`（红，二次确认）。
- 空态：标题`还没有房源` + 描述"先发布一套房源，审核通过后就能被租客看到。"+ `发布第一套房`按钮。

**看房预约入口卡**（白卡）
- 标题`看房预约` + 描述"确认时间、完成带看、沉淀成交线索" + 右箭头 → 跳预约页。

## 四、发布房源（pages/landlord/publish）

**表单卡（白卡）**
- 房源标题：输入框（占位"例：近地铁南向两居，采光好"）。
- 两列网格：租金（月租，数字）/ 面积（m²，数字）。
- 两列网格：区域（如 海淀区）/ 户型（如 两居）。
- 详细地址：输入框（小区、楼栋或附近地标）。
- 两列网格：出租方式（picker：`整租` / `合租`，默认 整租）/ 装修（输入框 精装/简装）。
- 亮点标签：输入框（逗号分隔，如 近地铁,可短租）。
- 配套设施：输入框（逗号分隔，如 空调,洗衣机,电梯）。
- 房源描述：textarea（写清通勤、采光、楼层、周边）。
- `提交审核` 主按钮（绿，loading 态）。

**校验**：标题、区域、地址、租金、户型 为必填；提交后提示"已提交审核"并返回上一页。
> 注：图片本版以空数组提交（预留图片上传位）。

## 五、看房预约（pages/landlord/appointments）

**预约卡（白卡列表）**
- 头部：标题`预约 #ID` + 状态徽标：`待确认`(橙)/`已确认`(绿)/`已取消`(灰)/`已完成`(蓝)。
- 行：看房时间 `viewingTime`；联系电话 `contactPhone`。
- 操作（按状态）：
  - `待确认(0)`：`婉拒`（ghost 浅底）+ `确认`（primary 绿）。
  - `已确认(1)`：`完成带看`（primary 绿）。
  - 其他状态无操作。
- 婉拒：弹确认框输入原因（默认"当前时间不便看房"）。

**空态**：`暂无预约` + 描述"有租客提交看房申请后，会出现在这里。"。

## 六、房东可复用的公共页（字段见租户端文档）
- 消息中心（`pages/message/list`）：接收租客预约/合同/账单类消息。
- 我的账单（`pages/my/bill`）：查看与房源相关的账单。
- 我的合同（`pages/my/contract` + `contract-detail`）：租赁合同查看。
- 评价房源（`pages/house/review`）：可对房源评分（房东也可用）。
